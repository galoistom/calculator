#+title: Calculator
this is a small project to test out the knowledge in chapter 4 of [[https://mitp-content-server.mit.edu/books/content/sectbyfn/books_pres_0/6515/sicp.zip/full-text/book/book-Z-H-4.html#%_toc_start][SICP]], it is basically a lisp interpreter that implement a sub of r5rs, but have a few more function realted to the mathmaticall calculation

* Usage
#+begin_src bash
calculator <option> code
#+end_src
where option are "-f/--file" to read from file, "-e/--eval" to read from args, and "-h/--help" for help
